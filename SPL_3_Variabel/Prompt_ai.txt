# PROMPT AI – PROGRAM SPL 3 VARIABEL

Buatkan program Python untuk menyelesaikan Sistem Persamaan Linear (SPL) tiga variabel menggunakan metode Eliminasi Gauss.

Ketentuan program:
1. Program menggunakan bahasa pemrograman Python.
2. Program dapat menyelesaikan tiga persamaan dengan tiga variabel, yaitu x, y, dan z.
3. Tampilkan matriks augmented dari sistem persamaan.
4. Lakukan proses eliminasi Gauss untuk membentuk matriks segitiga atas.
5. Lakukan substitusi mundur untuk mendapatkan nilai setiap variabel.
6. Tampilkan langkah-langkah perhitungan secara jelas.
7. Tampilkan hasil akhir nilai x, y, dan z.
8. Berikan penjelasan sederhana pada setiap bagian kode agar mudah dipahami oleh mahasiswa.

Selain kode program, sertakan:
- Penjelasan tujuan program.
- Penjelasan algoritma Eliminasi Gauss.
- Penjelasan proses perhitungan.
- Hasil output program.
- Kesimpulan dari penyelesaian SPL tiga variabel.

Buat program yang rapi, mudah dijalankan di Google Colab, dan dapat digunakan sebagai dokumentasi proyek mata kuliah Komputasi Numerik.
