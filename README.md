# PROYEK KOMPUTASI NUMERIK

## Deskripsi Proyek

Repository ini berisi kumpulan program sederhana yang dibuat menggunakan bahasa pemrograman Python untuk menyelesaikan permasalahan matematika dengan menerapkan metode numerik.

Proyek ini bertujuan untuk memahami konsep dasar metode numerik, menerapkan algoritma ke dalam program Python, serta mengetahui hasil perhitungan melalui pengujian program.

## Tujuan Proyek

1. Memahami konsep dan cara kerja metode numerik.
2. Mengimplementasikan metode numerik menggunakan bahasa Python.
3. Menyelesaikan permasalahan matematika secara komputasi.
4. Menampilkan hasil perhitungan berdasarkan algoritma yang digunakan.

## Daftar Metode

### 1. Metode Bisection

Metode Bisection merupakan metode numerik yang digunakan untuk mencari pendekatan akar persamaan nonlinear dengan cara membagi interval menjadi dua bagian secara berulang.

- Persamaan: f(x) = x³ - x - 2
- Interval awal: [1, 2]
- Toleransi error: 0,0001
- Jumlah iterasi: 15
- Hasil pendekatan akar: 1,521393
- Nilai fungsi: 0,000078

File program: `Bisection/metode_bisection.ipynb`

### 2. Metode Eliminasi Gauss (SPL 3 Variabel)

Metode Eliminasi Gauss merupakan metode numerik untuk menyelesaikan Sistem Persamaan Linear (SPL) dengan tiga variabel melalui proses eliminasi baris hingga diperoleh bentuk matriks segitiga atas, kemudian dilanjutkan dengan substitusi mundur.

File program: `SPL_3_Variabel/metode_spl.ipynb`
